# Biblioteca reutilizável

Materiais e mobília usados nos projectos — o que se poupa aqui em cada tour é a margem.

- **Fontes CC0/free:** Poly Haven (polyhaven.com — texturas/HDRIs), BlenderKit free tier, ambientCG
- **Organização sugerida:** `materiais/` (chãos, paredes, cozinhas), `mobilia/` (por divisão), `hdri/` (iluminação exterior)
- **Formato:** guardar como asset library do Blender (Asset Browser) num `.blend` por categoria
- Ficheiros grandes (>50 MB): não comitar — usar Git LFS ou manter local e listar aqui a origem/URL
